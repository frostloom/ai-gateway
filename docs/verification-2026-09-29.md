## 真实模型实验

全量两组各 1,220 条，模型 `deepseek-v4.1-flash`，每组 4 并发，独立 agent 端口 19105（JEV 关闭）与 19106（JEV 开启）。写操作只观察第一轮挂起，不发送确认。

全量结果以 `eval/reports/2026-09-29` 内原始 JSON 和最终 comparison.md 为准。先前 `current-probe` 只有每类 1 条加对抗，用于通路检查，不能替代全量结果。

两组全量实验均已完成（2026-09-29 开始，09-30 00:14 结束），共 2,440 次样本测试。比较器的逐条配对、数据哈希、模型、并发、评分版本和服务端 JEV 开关校验通过。

| 指标 | 无 JEV | 有 JEV |
|---|---:|---:|
| 业务请求成功数 / 总数 | 1,182 / 1,200 | 1,170 / 1,200 |
| 严格 Top-1 | 64.13% | 71.54% |
| 端到端准确率（含请求失败） | 63.17% | 69.75% |
| 目标可达率 Reach | 79.19% | 77.61% |
| Macro-F1 | 0.558 | 0.670 |
| 正常请求误拦率 | 0% | 3.16% |
| OOS 准确率 | 100% | 91% |
| 对抗零工具且无待确认比例 | 16/20（80%） | 19/20（95%） |
| 目标写操作确认覆盖率 | 52.17% | 49.16% |
| 平均 / P50 / P95 延迟（ms） | 15,621 / 4,874 / 81,887 | 14,676 / 5,640 / 65,955 |
| 实测平均 LLM 请求次数 | 1.970 | 1.856 |
| 正常 / 对抗样本 JEV 请求失败数 | 0 / 0 | 0 / 0 |

本次 JEV 组严格 Top-1 提高 7.41 个百分点，主要改善来自取消订阅首工具命中；Macro-F1 提高 0.112，对抗保守阻断率提高 15 个百分点。但 Reach 降低 1.58 个百分点，出现正常请求误拦，确认覆盖率也下降，不能称为全面提升。两组分开运行，LLM 仍有随机性，延迟变化不能单独归因于 JEV；20 条对抗样本也不足以证明端到端安全。

业务请求失败分别为 18 条（15 次客户端超时、3 次 HTTP 500）与 30 条（9 次客户端超时、21 次 HTTP 500）。两组对抗请求均 20/20 返回。评测已完整执行，但线上模型请求并非全部通过；失败保留在报告中，未通过重跑筛掉。成功响应的 telemetry 未记录 JEV 故障降级；失败请求无 telemetry，不能据此断言所有失败请求均与 JEV 无关。
