# 窗口收尾与预算领取沿用原操作context

V8首窗在300秒后仍完成下一claim写入，随后外层才停止。新实现把原窗口context从ledger打开传到advance及预算领取，在锁等待结束、历史校验结束和独占写入前后检查取消。旧无context包装入口仍受已绑定的操作约束，不能用Background绕过；成功进入新窗口时才绑定新操作context。窗口300秒、模型90秒及JEV10秒均不改变。

一旦进入预算尝试边界，整额永久责任保留。已经打开的文件仍完成Write、Sync、Close及目录同步；取消只令操作失败和owner停止，不删除证据、不释放预留。已写检查点或claim保留原字节与摘要，失败不返回成功advance token。
