# 现金事实解析离线修正（2026-10-23）

现金恢复真实复测通过后，首轮金额事实仍在自动报告中标为未评估。本次仅修正离线评测器，不改客服运行逻辑、不部署、不新增付费调用，也不改写历史报告或评分。

## 根因与改动

有限现金标签语法未覆盖“当前现金余额为…”和“你的当前可用现金余额是…”。此外，整段回复只要出现“如果”就排除所有事实，即使前面的独立首句已经明确陈述现金金额。

现在仅在回复直接以完整金额陈述开头时支持上述新增现金标签，避免放开条件或转述前缀。后文含条件建议时，只允许回复直接以现金标签和金额开头，并且第一个中文句号之前不含“如果”；仅检查第一条现金金额断言。条件/转述前缀、前导标点、未完整的现金前缀或没有完整首句时都不评估，也不放开显式账本数值。引述、假设、转述保持原有保守排除，其他种类的事实仍遵循原整段排除规则。隐式“账本余额也一致/与此一致”不被编造为新的数值断言。

现金金额 match 仅代表该断言与当轮权威快照相符，不能证明本轮确实读取、无越权、无写入或整段回答成功；这些仍须读取trace/审计、状态断言和独立语义复核。
