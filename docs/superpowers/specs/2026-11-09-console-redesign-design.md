用户空间包含概览、模型目录、工作台、余额与兑换、月卡套餐、用量、订单和 API 接入。操作客服常驻，可指引页面操作及查询账户。工作台提供模型对话。交互包含加载、错误、空状态、重复提交保护、输入校验、键盘操作、焦点管理及移动端布局。

## 模型与资金

模型目录仅展示已上架且启用上游配置支持的模型，沿用精确名称和既有通配语义。页面展示按量输入输出价格。

支付回调接入前，gateway、billing admin、客服工具的充值建单和模拟支付全部无条件关闭，演示环境变量不能绕过。月卡开通与换套餐也无条件关闭，取消已有续费仍保留。

管理员签发一次性余额码，明文仅在签发响应返回一次。持久化 SHA-256、前缀、金额分、有效期和兑换状态。用户只能向鉴权账户兑换。账户、券、流水与余额列在事务内锁定并提交。已同步的同账户重试保持幂等，其他账户再次使用拒绝。每账户每分钟最多十次有效格式尝试。

批量账本存在待结算扣款或 SQL/Redis 余额不一致时拒绝兑换，保留 Redis 扣款。余额差额无法区分未投影入账和未落盘扣款，不按差额自动恢复，需先完成账务核对。非批量模式保留既有账本恢复约定。

## 金额月卡

新套餐提供 WindowQuotaCent、WeekQuotaCent、CycleQuotaCent，表示滚动小时、滚动七天和当前订阅周期金额额度。页面显示额度金额、已使用百分比、余量和恢复时间。不同模型按预占时价格快照和实际用量核算金额，额度不足拒绝调用。

预占事务首次订阅读取即加行锁，锁后才建立额度读取快照，避免不同 billing 实例等待锁后遗漏已提交预占。旧订阅继续执行原权益，前端和客服只展示档次百分比与滚动小时。新版目录仅展示金额套餐。

已保存的套餐条款固定，修改权益需复制新套餐。套餐可启停，停用新版计划保留已生效周期并阻止新开通与续期。
