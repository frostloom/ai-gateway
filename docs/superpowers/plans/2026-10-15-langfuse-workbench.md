# Langfuse 客服评测工作台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将现有冻结任务、规则评分、审核和提示词接入本机 Langfuse，零外部推理。

**Architecture:** 扩展现有本地 API 同步机制，新增独立工作台计划/发布/读回工具；数据集与配置名称版本化，内容不符拒绝覆盖。现有规则评分工具保持原样。提示词按内容摘要归档，实际 generation 只关联同一基础提示词的固定版本，不改变请求或生产提示词来源。

**Tech Stack:** Python 标准库、本机 Langfuse 4.58.0 API、Go OTel。

**Spec:** 本文记录用户已批准的上一轮五项接入方案与边界。

## Global Constraints

- 不调用外部模型/JEV，不配置自动模型裁判或模型连接，不运行调试台推理。
- 保留 1220 原始案例、历史输出、任务定义和旧预检查包。
- 任务定义是开发集、AI 事后标注，非独立金标；必要追问不判错、未审核成功为 unknown。
- 本机 local_stub 验证独立展示，不得汇总成真实模型收益。
- 仅操作 localhost 的独立 evaluation 项目；写入前校验全部追踪，固定 ID 或按唯一版本名读回，网络失败留回执且不自动重试。
- 沿用当前工作区，不触碰用户未跟踪的 plate_sim.py；按既有授权最终提交推送。
