# 控制台重构实施计划

目标为完成用户端、管理端布局与业务语义重构，并核查服务器隔离及安全问题。依据同日 console-redesign-design.md，使用现有 Vue 3 与 Go，直接在用户工作区增量实现。

## 全局约束

保留全部既有未提交改动。服务器检查限定 ai-gateway。历史评测保持关闭。充值申请不得假称真实付款成功。月卡权益暂沿用已有滚动额度。

## 检查重点

空目录和上游禁用、重复提交与金额精度、用户会话过期、订阅未知状态、移动布局与前进后退。

- [ ] 为目录上游过滤、演示资金门禁和套餐配置校验编写失败回归，运行后实现对应服务端逻辑。
- [ ] 重建用户顶部导航与概览、模型目录、钱包，保留用量/接入，工作台支持连续对话与终止。
- [ ] 区分后台视觉和资源分组，新增套餐表单与启停管理。
- [ ] 补充客服操作入口与本地导航指引，资金步骤明确确认并抑制重复请求。
- [ ] 运行 Go 定向回归和前端 verify，以浏览器验证桌面/移动和真实构建后的交互。
- [ ] 独立审查并处理重要发现，输出远程安全检查结果与部署状态。

## 最新范围与执行分工

用户明确要求直接开发、双轴 code-review 后修复并上线，普通充值关闭，新增管理员生成的一次性余额码，月卡改为每窗口/每月的金额权益。frontend-design、design-taste-frontend、Hallmark 组合使用，主题以 aixcoder 原件为准。

- Root 实现余额码原子兑换、充值禁用、金额月卡后端、券前端、导航整合和独立容器部署。
- 独立前端任务 A 只修改上游渠道卡片、客服输入与指标视图。
- 独立前端任务 B 只修改月卡用户/管理视图与金额数据类型，接口字段由 Root 固定。
- 完成后按 code-review 分 Standards 和 Spec 两轴独立审查，修复后重新验证。
- 部署只重建 aigw-app 镜像并按需更新独立 aigw-edge 配置，记录全部 Myink 容器 ID，保留回滚镜像和原配置。
