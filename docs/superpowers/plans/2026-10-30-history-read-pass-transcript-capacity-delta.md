# History read-pass metadata capacity delta

The original46 local read-only acceptance failed with `stopped v8 evidence rejected: concrete predecessor`; its result and logs remain unchanged. A separate diagnostic called the same private WithPass chain and recorded the pass's retained first failure before Abort: `history transcript limit`. It reached 16,777,206 charged bytes, 18,110 records, 17,884 file entries, 141 directories, 78 namespaces and seven locks before End. Logical requests were 144,466, physical reads 18,019, cache hits 125,289 and cache payload 61,338,104 bytes. No baseline was returned and no End sweep occurred. There were no new model/JEV calls or claims.

The former 16 MiB transcript bound was an engineering estimate for this new, unfrozen protocol. Real historical inputs include direct inventory streams as well as the byte-reader entries counted by the earlier 275,644-read probe. The data demonstrates that the estimate is insufficient; a generic predecessor error does not establish a source, identity, binary-attestation or business-budget failure.

Root's explicit engineering decision changes exactly one production constant: charged transcript metadata capacity becomes 32 MiB. Original charging is preserved, including repeated key/path/SHA lengths and the fixed 512-byte record charge, namespace name charges and all directory/lock charges. No record compression, deduplication, eviction, skipped dependency, fallback or cross-call reuse is introduced.

The other fixed limits remain 65,536 transcript records, 1,048,576 logical calls, 128 MiB retained cache payload, 1 MiB per retained entry, four logical leaf slots and the existing global four physical slots. All first/End reads, uncached stream repetitions, identity/ctime/nlink/canonical checks, namespaces, locks, callback failure sealing and context checks remain unchanged. Thirty-two MiB is a bounded protocol charge, not a process RSS claim. Currency budgets, claim reservations, retry rules and business300/90/10 deadlines are unaffected.

Literal 32 MiB exact-boundary admission and overflow-failseal tests must fail against the old constant, then pass after the one-line change. Normal/race regressions and a narrow independent review precede root's fresh, uniquely named original46 acceptance run. The earlier failure is never overwritten or relabeled as a pass. This delta alone does not prove complete original-data acceptance, timing within300 seconds, a frozen V9 source or paid readiness.
