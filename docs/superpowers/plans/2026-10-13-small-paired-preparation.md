# 小规模配对评测准备 Implementation Plan

**Goal:** 固定代表案例和回答标准，提供受预算保护、逐臂持久化的配对运行接口与离线逐条报告；本轮外部模型/JEV调用为0。

**Architecture:** 扩展现有taskbench，不改1220原始档案。准备入口只选择冻结定义中的12个完整任务，并输出明确开发预期。模型HTTP传输层在每次尝试前持久化计数与单次费用上界预留，包含重试；未知usage/中断停止且不自动重发。配对runner交错两臂，写独占journal后执行，重放已有完成记录，不重新调用。报告使用现有独立状态/事实/语义审核口径，缺审核不发布完整任务率。

**Tech Stack:** Go标准库、现有taskbench/agent；本地测试替身。

**Constraints:** 不读.env，不请求外部模型/JEV；不动plate_sim.py或任何旧归档；不自动启动付费评测。用户已批准此前三项方案并要求自主完成，执行本轮不增加重复审批环节。沿用当前main；远程推送已持续授权。

**Ruling:** 真实运行接口采用显式注入ConversationDriver与受控HTTP传输，CLI只提供准备和离线报告，避免CLI直接发现密钥并扣费；未来授权运行需要明确构造真实适配器并启用paid许可。配置费用是预留上界/按声明价格重算费用，不冒充供应商实际账单保证；未知费用停止。

- [x] 配对runner以同case两臂交错，固定配置哈希，记录每臂开始/完成、逐轮原始结果和耗时；只跳过已完成臂、续跑未开始臂，不重发未知中断。逐条报告包含结构、事实、语义待审、追问/失败、调用/token/费用/延迟，保留未执行分母。测试先失败。

**Integration:** 验证通过后按已有授权提交推送main，并核对远程HEAD；实际提交号由最终汇报提供。

**Review Focus:** 预算在HTTP尝试前检查而非结束后；费用/usage缺失不是0；中断可能已扣费不能自动重试；恢复必须绑定同模型/提示词/工具/profile/代码与价格条件；未执行或失败案例不能从分母删除；必要追问和确认不是任务失败；无审核和local_stub不发布收益。
