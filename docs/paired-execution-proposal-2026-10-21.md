本轮核验基于 main `144602b107c3b7b9443620cd276af6b305616dd2`，完成了官方计费资料核查、完整12案例的本地请求测量，以及逐批执行提案。`allow_paid=false`、`ready_for_paid_run=false`；未运行外部模型/JEV推理，未修改产品代码、账户配置或消费限额。

## 账户计费核查结果

- 千问官方计费说明明确写明调用失败不产生费用，也不消耗免费额度。这里的失败指供应商认定的失败；客户端超时、断连、解析失败不能证明服务端未成功计费，仍按未知费用停止处理。
- Function Calling 本身不收额外工具费，工具描述按输入token计费；本项目的本机业务工具不是供应商联网搜索等内置收费工具。
- 官方资料说明账单按小时更新，可能延迟；调用后暂未看到账单不能证明免费。
- 官方CLI提供用量、账单查询，但管理命令需要管理登录，模型API Key不等于管理会话。本机未安装该CLI，本轮没有安装或启动新的登录流程。
- 已在现有Safari新标签打开官方按量付费账单页，实际显示“您当前还未登录”。因此本账号费率、折扣、余额和历史实扣均未读到；该标签保留供后续登录。
- JEV公开OpenAPI只列出模型列表和推理接口，所查文档没有账单/余额路径，也没有找到失败请求收费承诺。这不等于整个服务不存在管理功能或失败一定收费。

[收费核查证据](../eval/paired-pilots/2026-10-21-execution-envelope/billing-boundaries.json)包含官方来源、原件哈希、已证实和未证实的字段；没有归档私人账单或凭据。公开模型价格沿用[同日已核对证据](../eval/paired-pilots/2026-10-21-prepaid-readiness/public-price-review.json)。

JEV探针按当前客户端的model/state/questions形状序列化，在本机测量后仍委托Fake，不发送网络请求。单问题测量包括state和该问题的完整请求JSON，是字节指标，不是token。JEV公开请求体限制32MiB，本轮字节规模低于该限制；默认64k请求上下文、32k单问题上下文仍是另一维度。

[请求测量记录](../eval/paired-pilots/2026-10-21-execution-envelope/request-envelope.json)逐案例保留字节数和SHA，不包含请求正文、凭据或真实账单。测量是这些替身对话路径的证据，不能覆盖未来真实模型所有回答和工具调用路径；Fake返回的usage也是合成值，不能用来核定真实token。

所查官方索引、CLI和API定义中未找到可用于本次精确渠道/模型的非推理token计数接口，也没有调用未文档化的count_tokens路径。未使用别家模型的分词器推定收费上界，输入16384 token继续是声明范围。

原六场景替身脚本直接扩展到十二案例时，不支持重复确认/取消后确认，仍会发起充值预览，首次探针触发结构断言。只在临时替身脚本中补充无工具回复后，原有断言不变，12子案例及本地OTLP覆盖均通过；源码和冻结定义未改。此次接收器是本地OTLP替身，没有把它冒充为新一轮实际Langfuse入库；实际Langfuse/84评分读回仍见[上一轮报告](paired-prepaid-readiness-2026-10-21.md)。

## 执行前条件与停止规则

真实调用前仍需：管理登录后按当前模型和API Key核对账户账单/费率；确认JEV账户及失败请求费用边界；取得该渠道输入计数或其他可审核的收费包络证据；明确批准上述具体范围、次数与CNY/USD预算。这些未满足时禁止启动。

授权后仍需构造显式evaluation observer、固定JEV版本、独立初始账户、全新campaign/子预算/运行日志，并按当前执行代码重新计算绑定。若后续仅文档提交改变HEAD，不直接使用旧revision冒充新运行；实际驱动必须记录所执行版本，重新生成提案绑定后再运行。

达到任一次数/预留上限、模型HTTP/解析异常、usage缺失/超限、JEV失败或版本不符、账本损坏、结构不通过、observer导出失败时停止后续扩张，不自动重试付费请求。当前JEV守卫停止后续JEV，CampaignBatch在批次结束拒绝后续批次；**不承诺首次JEV失败瞬间停止本批所有模型回退**。每案例一批将这一剩余范围限制在该案例的尝试上限内。

每批完成后读回task/turn/generation、usage和确定性评分，独立审核回答及必要追问；语义未审保持unknown，不因结构通过就发布成功率。任何本地证据都不证明真实模型可用或产生了质量/成本收益。

[核验回执](../eval/paired-pilots/2026-10-21-execution-envelope/verification.json)记录探针、预留模拟和本地证据哈希；`probe-overlay.patch`及`prepare-proposal.go.txt`保留可审查的离线探针/生成逻辑。它们不是生产功能或可直接开启付费的入口。

独立只读审查已核对收费来源、请求日志、分批金额、停止行为和付费边界，未发现需修正的问题；产物哈希、探针补丁复原、源码未变和文档链接检查通过。本次审查不替代真实模型回答的语义审核。
