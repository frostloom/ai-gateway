## 已实现的规则

`internal/taskbench/conversation_*`从独立固定的manifest和文件SHA加载原定义。Driver接收固定用户续句、本人账户与同一会话标识，每轮返回独立取得的业务快照、预览状态和工具轨迹；订单占位符只替换为本人种子订单。适配器接口可以接实际服务，本轮执行的是本地对话替身，尚未新增实际agent HTTP适配器。

初始化先核验声明profile的余额、订阅状态和滚动窗口额度。初始化失败单列，排除有效任务分母；有效初始化后的HTTP错误、超时、缺少终态等仍是失败任务。HTTP错误产生的截断记录可复核，正常记录擅自缺轮、重复场景、错绑定义SHA、用户续句与计划不一致则拒绝整个输入。

必要追问单列统计，允许其后用户明确补参；不把必要追问直接算错，也不凭追问动作就认为任务完成。首轮诊断不进入整任务分母，但其结构失败、初始化失败、HTTP失败和待审核都有独立计数与退出状态。

预览与执行检查本人身份、工具、金额、订单与套餐绑定。确认前任何业务修改都失败；执行必须有前一轮正确pending以及单次confirmed工具轨迹。取消清除pending；重复确认、取消后确认不得再次修改状态。成功预览/读取需要对应成功轨迹；停止续费与退款不是同一操作。

终态核验现金余额与账本、充值/退款流水、本人订单状态、当前套餐/下期待换套餐、续费状态、本期到期日与额度。无操作阶段同时保护余额、订单、订阅、流水与额度；外部对照账户不得变化。未实现的终态字段明确失败，不能忽略后自动放行。

## 回答审核边界

结构通过后，逐轮动作解释、原来源逐事实要求、续轮answer约束和最终答复都必须有独立审核。审核项包含原要求、回复SHA、场景/账户/初始与当前状态/工具结果/预览/续句上下文SHA、审核人、方法、理由和结论。回复或工具结果被换掉，旧审核失效；缺审核标needs_review，不能当pass。

当前支持human、audited_offline，以及仅供替身测试的local_stub审核标记。recorded_run禁止local_stub审核。审核人身份和权威快照是受信输入来源，哈希用于防错绑，并不提供服务器执行或独立审核人的密码学证明。对复杂自然语言要求没有冒充通用自动语义判官；目录、账单等事实审核仍需足够的权威工具结果/外部审定证据，不能在证据缺失时自行批准。

原任务定义仍是AI事后开发标注，不是独立盲测金标。未来对真实模型的完整任务成绩，还需要实际agent适配、事实证据采集和独立审核/经过审定的确定性事实评分。仅凭本文的执行框架不能声称这些已完成。

## 复核命令

从仓库根目录执行，输出必须选择不存在的文件：

```powershell
go test ./internal/taskbench -run TestConversationArchivedStoreEvidenceReplay -count=1
go run ./cmd/conversation-eval -transcript eval/conversation-regressions/2026-10-13-local-v1/transcript.json -out eval/reports/conversation-review-new.json
go test ./internal/taskbench -run TestConversationRealStoreBranches -v -count=1
```

前两项不连数据库或网络；第三项需要本地3307测试MySQL，私有Redis自动创建，库自动删除并核验清理。基础设施不可用会明确skip，不能把skip当作真实执行证据。

CLI不读取.env，没有模型地址、在线模式或付费选项；本地记录按一次读取的原字节计算SHA。已有报告不能覆盖。exit 0仅表示复核过程无结构错误，仍可能needs_review；exit 1表示任务/诊断失败或初始化失败；exit 2表示输入或写报告配置错误。完整任务正确率在有效任务仍有待审核时保持null。
