# 计费压测过程

本机闭环。模拟模型延迟 0 毫秒，64 个租户，每档大约 10 秒。下面按时间写每次改了什么、四档各完成多少。这些数字是这一台 Mac 上的结果，不能当成生产容量。网关和 New API 没有同时跑。

每秒完成等于成功次数除以这一档实际耗时。一半耗时是 p50。

### 11 月 8 日 01:28　提交之后整批发给 Kafka

请求只等 Redis 扣款。明细放在内存里。每 5 秒一个 MySQL 事务写入账单和余额变动，提交之后这一批再发给 Kafka。刷账期间后面的请求只看 Redis。成功调用不再把「失败次数是 0」写回 MySQL。

先单测 64，目录 `20261108-012800`：每秒 2237.2，22411 次全成功，一半耗时 23.7 毫秒。
