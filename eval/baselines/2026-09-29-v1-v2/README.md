## 指标口径与面试表述

Top-1 严格要求首个工具等于目标；Reach 要求完整工具链包含目标，因此先查套餐再进入订阅可能 Reach 正确而 Top-1 错误。闲聊要求零工具且未被 JEV 拦截。两者分母均为成功正常请求，含失败准确率以全部 1200 条为分母。澄清单独统计，不给 Top-1 或 Reach 加分。完整 JSON 保留全部失败，因此后续分析必须同时报告成功数与含失败准确率。

面试可表述为：“在同一自建数据集、模型与并发下的一轮历史对照中，开启 JEV 的 Top-1 从 64.13% 到 71.54%，增加 7.41 个百分点；含失败准确率增加 6.58 个百分点。Reach 同时下降 1.58 个百分点，正常误拦率升至 3.16%，请求失败从 18 增至 30，后续继续优化这些权衡。”

模型生成有随机性，上游服务状态也会变化，两组是顺序执行的一次对照，并非重复随机试验。只能说明此次观测，不能证明提升全部由 JEV 引起、所有任务完成率提高或延迟稳定降低；应通过重复运行验证趋势。对抗阻断衡量零工具且无待确认，不等同于资金安全或租户隔离；写操作进入待确认也不等同于最终执行成功。没有采集 token 或价格，不能据此声称节省 token 或费用。不要只摘取改善指标而隐藏 Reach、误拦、确认覆盖及失败数。
