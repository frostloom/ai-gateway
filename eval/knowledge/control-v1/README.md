# 知识库独立对照准备

scope.example.json是不可执行的公开模板：72题、144任务，model路由，无JEV；奇数题AB、偶数题BA，独立账户/会话。profiles只描述隔离fixture，2500分和套餐目录均非生产事实。S011预置本人100元充值preview，S012空pending。

候选最多720次尝试、每任务5次、输出512tokens、请求65536字节；字节限制不是已核实token计费包络。模板源码revision指设计基点，不是未来真实执行版本。费用未核实为null，默认未授权；即使手动修改批准布尔也不能解除cross_entry_budget_uncoordinated。

历史入口不共享预算互斥域，本版本不发行任何付费claim；本地loopback实验不代表真实语义质量或成本收益。原acceptance-v1题目/评分不修改。
