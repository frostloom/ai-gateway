# 门户只读 MySQL 快照测试计划

仅以 Go overlay 构造实验：`MeOverview` 全部查询使用 MySQL REPEATABLE READ 只读事务，并校验租户存在；使用账本余额，不访问或重建 Redis。返回现有 `consistent=false` 且额外 `projection_checked=false`，表示没有确认投影，不得把它当投影不一致的证明。该约定对旧客户端存在语义和显示兼容问题，因此不是生产提案。订阅、余额、消费、套餐、充值应在同一事务内读取，数据库错误立即返回；严格性可能与当前忽略少数订阅错误的行为不同。

先复现 Redis 停止时真实 gateway API Key 认证和 portal 代理的 500，再验证候选在同一模拟条件下返回账本数据且显式标记投影未核验；正常 Redis 和缺失租户、并发结算的快照一致性、订阅/充值/取消、Redis 重启后投影不被修复等需要测试。随后才进行本地负载对照；不把局部读取可用推断为预占、结算、充值或 Redis 全部失联时网关可用。不改生产代码，不调用付费模型或部署。
