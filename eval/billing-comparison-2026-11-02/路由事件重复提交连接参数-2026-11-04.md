# 路由事件重复提交与 MySQL 连接参数

## 问题和范围

为研究替代全局锁内同步写入的可靠路由回报，`router_event_candidate_test.go` 的测试原型将事件身份和 provider 状态更新放在同一 MySQL 事务；它未接入正式 router 或 gateway。原型使用 GORM 的 `OnConflict DoNothing` 后判断 `RowsAffected == 0` 是否为重复事件。针对 MySQL 驱动的 `clientFoundRows=true`，隔离测试用相同事件 ID 连续上报失败两次，三轮均出现一条事件但渠道失败计数为 2；`router-event-found-rows-red-20261104.txt`。同次默认连接参数的 20 个事件、40 次并发上报仍通过，说明此前测试未覆盖该连接参数。此问题属于测试候选，不能据此声称正式路由已采用事件表或存在同一实现缺陷。

## 测试候选修正

测试原型改成普通插入；发生 MySQL 1062 时读取已存事件，核对 provider 和结果，相同则作为重复，不同则报冲突。该测试事件表只有 ID 主键；不能把对 1062 的处理推广为可安全忽略其他唯一约束错误。事件插入和 provider 更新仍在同一事务中；其他 SQL 错误按原样返回。

隔离 MySQL 8.0.40 / Redis 7、race 下三轮最终回归：

- `clientFoundRows=true`：同一已提交事件串行重试，再由 16 个 goroutine 同时重放，计数和事件数均为 1；同 ID 不同结果被拒绝。
- 默认参数：20 个不同事件各两次并发提交，事件数和失败计数均 20，并验证冲突与注入回滚。
- 默认参数：禁用渠道时保留事件但不改变计数，重新启用后重放不再次应用。

原始输出 `router-event-found-rows-final-20261104.txt`。这不证明 `clientFoundRows=true` 下首次插入与重复插入的所有并发时序、跨进程或 COMMIT 回执丢失；也未覆盖线上连接参数、死锁重试、事件清理、跨实例顺序、缓存及熔断状态、正式 HTTP 确认和网关重投。更改了写法，先前该原型的性能数字不再直接适用于新版本；需重新测量。事件表尚未接入生产，不得部署或据此声称完整路由方案安全。

## 修正后的故障回归

使用默认连接参数，`bash eval/billing-comparison-2026-11-02/run-router-event-ack.sh` 在真实提交成功后由测试驱动分别注入普通错误和 `driver.ErrBadConn`，每种各三轮：重试后仍一条事件、首渠道计数 1，跨渠道复用 ID 被拒；日志 `router-event-found-rows-ack-regression-20261104.txt` SHA-256 `1ac1a6e51474c03d47170a69301b0103e40538f0febcc0ebf0f4a19a106a03e2`。这是驱动包装模拟，不是实际网络 COMMIT 响应丢失。

`bash eval/billing-comparison-2026-11-02/run-router-event-process.sh` 三轮在子进程提交后强杀，再重试，均一条事件和一次失败计数；日志 `router-event-found-rows-process-regression-20261104.txt` SHA-256 `34438a7f7b5d6035747e0183d0824ed7025e422d19547e8cdf173afbcc2bd5a5`。两项均为隔离数据库、默认连接参数、测试候选，不证明 `clientFoundRows=true` 下相同故障或正式服务的恢复。

## 首次并发提交及修改后的组件负载

新测试在 `clientFoundRows=true` 下通过屏障同时启动 16 个 goroutine，向一个尚无事件的渠道提交同一 ID；三轮均无调用错误、最终一条事件及一次失败计数。此后仍执行串行和 16 路并发重放、参数冲突；默认参数并发事务及禁用渠道测试同次通过。屏障保证一起释放，并不保证数据库插入同时到达；没有覆盖跨进程或所有调度。输出 `router-event-found-rows-first-race-20261104.txt` SHA-256 `5f30e991fd6ac04aae6d708f0d17fae0605ec93b7c01af1c5af99e2285fc9558`，更新测试 SHA-256 `3a5a59d7a3c9cf4b33cacc4ccea85019e573ad47a8a8a066e8ae6b72a49151a7`。
