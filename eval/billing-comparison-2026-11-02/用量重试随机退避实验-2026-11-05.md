# 用量重试随机退避实验

## 范围和候选

现有测试候选在首次用量上报返回暂时性错误后固定等待 100ms 再试一次。本次只在测试 overlay 探索每次从 **50–150ms（含端点）均匀随机选择**一次等待，平均目标仍为 100ms；不修改生产 handler。两者均最多尝试两次、有 3 秒单次和 10 秒总预算；随机数仅用于分散时间，不用于安全令牌。随机退避不减少最坏重试次数，不替代限流、持久恢复或对账。

## 人为同步错误的纯计时实验

`TestUsageRetryPulseTiming` 在同进程启动 128 个真实 gateway handler，但 billing 是内存替身；全部首报在 barrier 同时返回合成 Unavailable，第二次由替身接受。模型为本地模拟，HTTP 使用 recorder，无实际数据库访问。统计第二次 `ReportUsage` 入口时间；10ms 峰值为任意连续 10ms 窗口内最多次数。`go test -race -count=3`：

| 等待方式 | 轮次重试分布跨度 ms | 轮次 10ms 峰值 |
|---|---|---|
|固定 100ms|1.964 / 1.766 / 3.280|128 / 128 / 128|
|随机 50–150ms|98.778 / 98.882 / 99.362|24 / 19 / 20|

每轮 128 个模拟 HTTP 200、128 次 settle。这个强制同步的极端替身展示固定退避可能同时唤醒，不代表真实数据库或所有负载的峰值；随机组耗时分布本身变宽，不能据此称总吞吐提高。

## 真实隔离账本的响应丢失突发

`TestUsageRetryRealJitterBurst` 在 16 账户上同时运行 128 个真实 gateway handler、回环 billing gRPC、MySQL/Redis 与本地模拟模型；每个测试 bridge 先等待真实 ReportUsage 成功，再人为返回 Unavailable，第二次使用真实 gRPC；HTTP 为 recorder。两种 overlay 先后各三轮，记录第二次调用的入口时间：

| 等待方式 | 轮次 10ms 峰值 | 轮次第二次调用跨度 ms | 轮次 P95 / P99 ms |
|---|---|---|---|
|固定 100ms|8 / 8 / 13|1863.512 / 1165.570 / 1461.510|2252 / 2289；1544 / 1574；1988 / 2017|
|随机 50–150ms|5 / 6 / 7|1437.959 / 1649.610 / 1046.265|1904 / 1927；2043 / 2061；1357 / 1380|

每轮 128 个 HTTP 200、每请求两次上报、128 已结算、pending 0；逐请求事件数量和每账户 Redis 与账本一致性核对通过。两组第二次上报各 128 次，未降低总请求量；首次真实数据库事务完成时间已经自然分散。前一组独立运行中固定峰值 7/11/7、随机 6/8/8，两组存在重叠。只有先后各数次短时突发、主机共享且分别新建容器，不能证明随机退避改善真实数据库压力、端到端性能或生产容量。

加入随机等待后，真实 handler + gRPC + Store 的发送前失败、提交后模拟响应丢失、首次超时、永久冲突、持续 Unavailable、accepted=false、32 并发和首次事务尚未返回的交错测试各三轮 race 通过（`usage-retry-jitter-correctness-20261105.txt`）。这不改变关键缺口：持续失败仍可能产生无 usage 的 HTTP 200/pending；本地进程死亡、网络分区、跨实例、流式、Kafka、重试预算和故障风暴下资源饱和仍未验证。没有实际数据库 CPU、连接池等待或错误持续期间负载证据；候选不可部署。

## 复现

```sh
# 固定 100ms 测试候选
TEST_USAGE_RETRY=1 TEST_USAGE_RACE_PATTERN='^TestUsageRetry(PulseTiming|RealJitterBurst)$' \
  bash eval/billing-comparison-2026-11-02/run-reconciler-usage-scan-race.sh
# 50–150ms 随机等待候选
TEST_USAGE_RETRY=1 TEST_USAGE_RETRY_JITTER=1 TEST_USAGE_RACE_PATTERN='^TestUsageRetry(PulseTiming|RealJitterBurst)$' \
  bash eval/billing-comparison-2026-11-02/run-reconciler-usage-scan-race.sh
# 随机等待正确性
TEST_USAGE_RETRY=1 TEST_USAGE_RETRY_JITTER=1 \
  TEST_USAGE_RACE_PATTERN='^TestUsageRetry(RealGatewayStore|ConcurrentRealGatewayStore|WhileFirstTransactionInFlight)$' \
  bash eval/billing-comparison-2026-11-02/run-reconciler-usage-scan-race.sh
```

脚本仅创建/清理本次随机隔离 MySQL/Redis；无候选开关时两项专用 timing 测试显式 skip（`usage-retry-jitter-default-skip-20261105.txt`），避免误认为测试了正式 handler。HEAD `42d8ef8e5ca2471b18800e50f8e7a57fbcfdd47f` 加未提交工作树，均无生产数据、付费模型、部署或提交。
