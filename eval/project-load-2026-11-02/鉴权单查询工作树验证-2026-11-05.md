# 鉴权单查询工作树验证

参考减少鉴权热路径数据库往返，将 `Store.ValidateAPIKey` 的普通 Key 与浏览器 session 验证放入同一条 MySQL 查询；使用 `BINARY` 比较保持原先 Go 字节级 session 名称判断，仍检查租户、Key 状态、到期时间及浏览器用户和 session。此改动没有引入 Redis 鉴权缓存，也不能据此声称整网关性能提高。

隔离 MySQL/Redis 上，浏览器鉴权查询次数原实现三轮均为 2（`auth-main-single-red-v2-20261105.txt`）；修改后三轮分别通过单条查询、取消及关闭数据库拒绝、名称大小写和身份状态测试（`auth-main-single-green-20261105.txt`）。首轮尝试因测试仅允许 overlay 而三次 SKIP（`auth-main-single-red-20261105.txt`），随后新增独立测试开关后才取得有效红灯。此次对照测试中的单查询参考与工作树实现相同，不能当独立等价证明；此前接入前的对照和完整网关性能波动见 [单查询接入对照](鉴权单查询接入对照-2026-11-05.md)。`git diff --check` 通过。
