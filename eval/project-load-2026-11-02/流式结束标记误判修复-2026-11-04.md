# 流式 `[DONE]` 正文误判修复

当前分支修复前，`internal/gateway/handler/chat.go` 的 `relayStream` 用 `strings.Contains(line, "[DONE]")` 判断结束。模型正文包含同样文本时，网关会提前停止读取后续帧，丢失后续内容及最终 usage，并按已转发正文估算结算。`python3 eval/project-load-2026-11-02/run_upstream_truncated_safety.py` 使用真实 loopback SSE 与 fake billing/router 复现：仅转发首行 `literal [DONE] text`，后续 `continued` 和真实 usage 未读取，按估算值上报；日志 `stream-done-content-red-2026-11-04.txt`。这是本地模拟，不是生产事故或真实供应商费用证据。

修复后仅当去除行首尾空白后是 `data:` 字段、其值精确为 `[DONE]` 才结束；正文 JSON 或 SSE 注释包含相同文本不会终止。完整 handler 包加定向测试以 race 运行，包含正文、注释和正常最终 usage，日志 `stream-done-sentinel-suite-2026-11-04.txt`。前一次修复后输出 `stream-done-content-green-2026-11-04.txt` 也保留。当前 `chat.go` SHA-256 `f69f290db09b00c5401f05088e7ebef857b59829035e802023fe987ca64b380b`，工作树有其他未提交修改。
