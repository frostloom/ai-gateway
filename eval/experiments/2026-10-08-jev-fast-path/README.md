## 快路径真正改了什么

只接受首次独立、无参数、当前本人余额/默认近7天消耗/全部套餐目录/当前本人订阅查询。意图与查询形态置信度≥0.90，合法性≥0.85，风险分<0.5且风险置信度≥0.80。类型、必填字段、有限概率都经过校验；复合、否定、写入、时间筛选、历史、待确认及额度歧义回退。执行层不靠关键词选正向工具，不放宽充值/退款/改套餐等用户确认；直接返回真实工具结果并保留同租户审计、普通对话历史及失败遥测。

配置为 `JEV_FAST_PATH=1`、`JEV_FAST_PATH_MIN=0.90`，代码默认不开启。提示组与快路径组提交相同JEV问题；首轮安全拦截和确定性确认/取消不算业务快路径收益。旧报告的 `jev_short_circuit` 是安全短路字段；业务快路径用新增 `jev_fast_path`，两者不能混算。
